# Bearforj Shaders changelog

## 0.6.7

Honest status. “Done in code” means the change is in this branch. It was not run in Skyrim, and the DLL was not linked here. No ray tracing was added.

### English

1. Water. Done in code. Refraction reads the displaced crest (`MPosition`). One hull covers light counts below technique 8. The wave grid, slider and shared clamp stay at 8. The 4-light permutation still compiles with refractions. Not compiled with fxc on this machine.
2. Starter set. Done in code. Screen Space GI and volumetric shadows start off. Raised ground is the feet bubble unless “raise the whole near field” is on. `PHYSICAL_SKY` is defined only for sky shaders. Skylighting probes stay at quality 1, not the maximum. Fur, waves, wetness, linear lighting and the light limit stay on. Volumetric shadows is a core feature, so the menu can lock that toggle off. The user may be unable to turn it back on from the UI.
3. FOMOD. Done in code, schema-valid. One weather page and one light page. True Light and Light Placer are the default path. Lux is a separate choice, recommended off, and not selectable while True Light is active. It does not install Lux files. Stop text is Russian and English. The picture step stays hidden until the six gate flags are yes. A failed check installs only the stop note. Limits: the XML checks that a named file is active. It does not read True Light 3.6.5, Light Placer 5.0.0, Window Shadows Ultimate 1.4.6 or Embers XD 3.3.0 as version numbers. Helios is skipped when the game version is at least 1.7.0. Below that, including 1.6.1170, a Helios plugin file is required. The exact build 1.6.1170 is not tested, and Luma, MMSF, Tweaks, ATLM and XEMI filenames are not invented. Two active weather plugins are not blocked: the weather check passes if any listed plugin is active. Prism has no profile and is not in the weather list. The plugin filename is unknown. Existing weather profiles already set `TonemapMix`. The installer was not clicked through in a mod manager. `assemble_pkg.py` was not run: it still reads `packs.json` from a path that is not in this checkout, and it needs a staged package plus a DLL.
4. Picture preset. Done in code. C++ defaults are the 1440p column. The nine `fVolumetricLighting*` keys are written into `SettingsDefault.json` and copied onto the in-memory display settings. `Skyrim.ini` is not rewritten. Interior warmth 0.62 and +0.3 EV apply per frame when the sky is not full exterior. A 4K frame (height at least 2160 or width at least 3840) moves bloom, ray quality, cloud march, cloud steps, cloud-shadow opacity and grain to the 4K column once, and only for keys missing from `SettingsUser.json`. The plugin overwrites `SettingsDefault.json` from those defaults on startup. Not verified in game.
5. Volumetric clouds. Done in code. Coverage is the weather slot times the mean enabled-layer alpha. While the march is on, the uploaded vanilla-cloud flag is off, Cloud Relight is uploaded off, and cloud-shadow opacity is uploaded as 0.2. While the march is off and those values are still the defaults, Cloud Relight is uploaded on (silver lining mix 1, spread 0.35) and opacity 0.2 is uploaded as 0.85. The shadow cookie is rendered every other frame and multiplies the sun in `ISVolumetricLightingGenerateCS` with one sample. Steps default to 40, and to 32 at 4K when the user has not saved the step count. The cubemap already updates two faces per frame. Not verified in game. `TESWeather::ColorTimes::kDay` was not compiled here.
6. Wet forest and grass. Done in code. Tree albedo scale 0.72, roughness scale 0.55, gloss +0.18 and shininess 1.45. Extra gloss fades out by about 20 m. Distant trees still darken. Grass wet roughness is 0.04. The wind path is unchanged. Not verified in game.
7. Placed-light shadows. Done in code. The shadow pool stays at the installed count. The scheduler budget is 4 outdoors and 6 indoors. Lights whose NiLight name, editor ID or form name contains candle, magelight or magiclight are skipped, and a NiLight name containing “particle” is skipped. Inverse square starts on. A particle light with none of those words still competes for a slot. Not verified in game.
8. Shader cache. Done. No prebuilt cache is in the gate installer or the GitHub packager. Cache arguments to the packager are ignored. Background compiler threads stay clamped to 1–2. The narrower first launch is the starter-set cuts in item 2, the single water hull and the fur distance cuts. There is no separate permutation allowlist beyond that.
9. Fur. Done in code. Fur stays enabled. Near shells stay in the 8–12 band, 4 from 8 m, 2 from 15 m, and none from 25 m (70 units per metre). First person uses the near band. The overlay uses the shell count recorded for that body. Not verified in game.

FSR. Done in code in the previous commit. Runtime FSR4 can be turned on for Radeon RX 6000 (Navi 21, 22, 23 and 24, including the RX 6950 XT). The switch is experimental and is not turned on by itself. RX 7000 and RX 9000 keep the existing switch. If the provider does not start, that session uses FSR 3.1. The public FidelityFX SDK is still v2.3.0 (`60f4ea8`). The signed DLLs were not replaced. Whether Adrenalin 26.10.1 accepts those DLLs on an RX 6950 XT was not tested. Ryzen integrated graphics stay hidden.

Checks on this machine: feature INIs, the slot audit with the allowlist, FOMOD schema validation, the GitHub package tests and JSON parsing were run. The DLL build was not: CMake here is 3.28 and the preset asks for 4.2 plus the Windows ClangCL toolchain. `fxc_all.py` was not run: Wine and `fxcw.exe` are not on this machine. `tools/extract-i18n.py --check` still fails on a drift that was already in the tree. This change adds no new `T()` strings. `tooltips.py` was not run.

### Русский

1. Вода. Сделано в коде. Преломление читает смещённый гребень (`MPosition`). Один hull закрывает число огней ниже техники 8. Сетка, ползунок и общий зажим остаются на 8. Сборка варианта с четырьмя огнями и преломлением сохранена. fxc на этой машине не запускался.
2. Стартовый набор. Сделано в коде. Экранный GI и тени внутри лучей выключены при старте. Подъём земли — пузырь под ногами, пока не включено «поднять всё ближнее поле». `PHYSICAL_SKY` задаётся только шейдерам неба. Пробы неба остаются на качестве 1, не на максимуме. Мех, волны, мокрота, линейный свет и лимит огней остаются включены. Тени внутри лучей — основная фича, поэтому меню может заблокировать этот переключатель. Из интерфейса его может быть нельзя включить обратно.
3. FOMOD. Сделано в коде, схема сходится. Одна страница погоды и одна страница света. Путь по умолчанию — True Light и Light Placer. Lux — отдельный пункт, по умолчанию выключен, и его нельзя выбрать, пока активен True Light. Файлы Lux установщик не кладёт. Текст стопа на русском и английском. Пресет скрыт, пока все шесть флагов не станут «да». При провале ставится только записка. Ограничения: XML проверяет, что названный файл активен. Номера True Light 3.6.5, Light Placer 5.0.0, Window Shadows Ultimate 1.4.6 и Embers XD 3.3.0 он не читает. Helios пропускается, если версия игры не ниже 1.7.0. Ниже, включая 1.6.1170, нужен файл плагина Helios. Точная сборка 1.6.1170 не проверяется. Имена файлов Luma, MMSF, Tweaks, ATLM и XEMI не выдуманы. Две активные погоды не блокируются: проверка проходит, если активен любой плагин из списка. Профиля Prism нет, и его нет в списке погод. Имя плагина неизвестно. У уже лежащих профилей погоды `TonemapMix` свой. Установщик в менеджере модов не прощёлкивался. `assemble_pkg.py` не запускался: он всё ещё читает `packs.json` по пути, которого в этом дереве нет, и ему нужны разложенный пакет и DLL.
4. Пресет картинки. Сделано в коде. Умолчания C++ — колонка 1440p. Девять ключей `fVolumetricLighting*` пишутся в `SettingsDefault.json` и копируются в настройки отображения в памяти. `Skyrim.ini` не переписывается. Тепло дома 0.62 и +0.3 EV считаются каждый кадр, когда небо не полное уличное. Кадр 4K (высота не меньше 2160 или ширина не меньше 3840) один раз переводит блум, качество лучей, марш облаков, шаги, непрозрачность тени облака и зерно в колонку 4K, и только для ключей, которых нет в `SettingsUser.json`. При старте плагин заново записывает `SettingsDefault.json` из этих умолчаний. В игре не проверялось.
5. Объёмные облака. Сделано в коде. Покрытие — слот погоды, умноженный на среднюю альфу включённых слоёв. Пока марш включён, в буфер уходит выключенный флаг плоских облаков, выключенный Cloud Relight и непрозрачность тени 0.2. Пока марш выключен и значения всё ещё умолчания, Cloud Relight уходит включённым (серебряная кромка 1, разброс 0.35), а непрозрачность 0.2 уходит как 0.85. Печенье тени рисуется через кадр и одним семплом умножает солнце в `ISVolumetricLightingGenerateCS`. Шаги по умолчанию 40, на 4K — 32, если игрок не сохранил своё число. Куб и раньше обновляет две грани за кадр. В игре не проверялось. `TESWeather::ColorTimes::kDay` здесь не компилировался.
6. Мокрый лес и трава. Сделано в коде. У дерева альбедо 0.72, шероховатость 0.55, глянец +0.18, блеск 1.45. Лишний глянец сходит примерно к 20 м. Дальние деревья всё равно темнеют. Мокрая шероховатость травы 0.04. Путь ветра не тронут. В игре не проверялось.
7. Тени поставленных огней. Сделано в коде. Пул теней остаётся на установленном числе. Бюджет планировщика — 4 на улице и 6 в доме. Пропускаются огни, у которых имя NiLight, Editor ID или имя формы содержит candle, magelight или magiclight, и имя NiLight содержит «particle». Обратный квадрат включён с самого начала. Огонь частицы без этих слов всё ещё может занять слот. В игре не проверялось.
8. Кэш шейдеров. Сделано. Готового кэша нет ни в установщике с проверками, ни в сборщике пакета для GitHub. Аргументы кэша сборщик игнорирует. Фоновые потоки компилятора зажаты в 1–2. Более короткий первый запуск — это срезы из пункта 2, один hull воды и срез меха по дистанции. Отдельного списка разрешённых вариантов шейдера сверх этого нет.
9. Мех. Сделано в коде. Мех остаётся включён. Вблизи 8–12 слоёв, с 8 м — 4, с 15 м — 2, с 25 м ничего (70 единиц на метр). От первого лица берётся ближняя полоса. Оверлей использует число слоёв, записанное для этого тела. В игре не проверялось.

FSR. Сделано в коде в прошлом коммите. Runtime FSR4 можно включить на Radeon RX 6000 (Navi 21, 22, 23 и 24, включая RX 6950 XT). Переключатель экспериментальный и сам не включается. На RX 7000 и RX 9000 остаётся прежний пункт. Если провайдер не создаётся, эта сессия использует FSR 3.1. Публичный FidelityFX SDK по-прежнему v2.3.0 (`60f4ea8`). Подписанные DLL не менялись. Примет ли их Adrenalin 26.10.1 на RX 6950 XT, не проверялось. Встроенная графика Ryzen скрыта.

## 0.6.6

### English

- Removed Screen Space Physical Particles, including its rain, snow, sprite atlas, settings and menu entries. That simulation was the stutter.
- Removed Footstep Kick Particles, the old Footstep Particles entry, Native Particle Physics, Physical Blood, Physical Leaves and Precipitation Physics.
- Kept GPU Footstep Particles. Physical Effect Particles is its own small spark, magic and optional fire-ember pool (a few thousand particles, not the old 160k simulation).
- Removed any remaining Unified Water and Water Cache package traces.
- New installs and Restore Defaults use Linear Lighting with ACEScg, ambient 0.32 and saturation 0.92. Skylighting stays on the maximum probe grid. Weather color adaptation is unchanged.
- The shader window title "Bearforj Shaders" sits beside the Mish Mish logo.
- Rain refraction and the raindrop ripple math already matched the 2026-10-22 AIO build (Raindrops.png and optimized-ggx.hlsli are byte-identical). The AIO Wetness Effects file is an older subset, so it was not copied over the current shader.
- Raindrop ripples and splashes show on wet ground again. Flat puddles are still stronger, but a slope no longer turns the impact strength to zero.
- Rain on a character starts as droplets at the head and moves down. The wet area darkens after the droplets. In water, only the part under the surface darkens as he wades. The whole body soaks at once only when it is completely under water. Droplets stay off the submerged part, then run down and thin out as he dries. Hair uses the same rule. Actor darkening follows the stronger 0.13.2 curve (porosity times wetness squared, times 2.4, then a 0.78 absorption).
- During snowfall a light coat settles on upward surfaces of the player, NPCs and creatures, and melts off when the snow stops. It stays a dusting, not a heavy blanket. Roofs block it.
- Cold weather shows breath from Wet and Cold's meshes (isparks, CC BY-NC-SA) on NPC Head [Head], and on a few creature nodes when those bones exist.
- Water keeps the shallow-color normalization that stops orange shallows, the existing shore wetness on sand, and a soft foam tint where the water thins out at the beach. Extra sheets of waves and foam under the surface were not added.
- Snow, mud and sand stand up (60, 18 and 10 units by default). A foot sinks about 65% of that layer, and the old footprints stay when the raise is zero. The raise fades out before the tessellation range so it meets the flat far ground. Shallow sand hollows near water are lowered. Legs standing in snow pick up a coat up to the drift surface.
- The existing water mesh is displaced by nine Gerstner waves. Rivers and waterfalls (flowmap) are not moved. The wave height fades to a flat plane between 4000 and 7000 units. Shore depth is one land-height grid shared by the mesh, the camera and actors, so the waterline does not swim with the camera. The last 4 units of depth at the shore stay on that plane. Fog, refraction and caustics use the displaced surface.

### Русский

- Убраны Screen Space Physical Particles: дождь, снег, атлас спрайтов, настройки и пункты меню. Эта симуляция дёргала кадр.
- Убраны Footstep Kick Particles, старые Footstep Particles, Native Particle Physics, Physical Blood, Physical Leaves и Precipitation Physics.
- GPU Footstep Particles остались. Physical Effect Particles — отдельный маленький пул искр, магии и по желанию искр от костра (несколько тысяч частиц, не старые 160 тысяч).
- Следы Unified Water и Water Cache из пакета убраны.
- Новая установка и «сброс по умолчанию»: линейный свет с ACEScg, ambient 0.32, насыщенность 0.92. Skylighting на максимальной сетке проб. Подстройка цветов под погоду не тронута.
- В окне настроек шейдеров рядом с логотипом Миш Миш написано «Bearforj Shaders».
- Преломление дождя и математика кругов от капель уже совпадали со сборкой AIO от 2026-10-22 (Raindrops.png и optimized-ggx.hlsli побайтно одинаковые). Файл Wetness Effects из AIO старше нашего, поэтому поверх текущего шейдера он не копировался.
- Круги и брызги от капель на мокрой земле снова видны. На плоских лужах они сильнее, но наклон больше не обнуляет силу удара.
- Дождь на персонаже начинается каплями с головы и спускается вниз. Потемнение приходит следом. В воде темнеет только то, что под поверхностью, по мере захода в воду. Весь персонаж промокает сразу только когда он полностью под водой. Капель нет на затопленной части; после выхода они стекают, редеют и пропадают по мере высыхания. Волосы по тем же правилам. Потемнение — кривая 0.13.2: пористость на квадрат мокроты, на 2.4, затем поглощение 0.78.
- В снегопад на верхние поверхности игрока, NPC и существ ложится лёгкий слой и тает, когда снег кончается. Это пыль, не тяжёлый сугроб. Под крышей снег не садится.
- На холоде видно дыхание. Меши Wet and Cold (isparks, CC BY-NC-SA) крепятся к NPC Head [Head], а у части существ — к их костям, если такие есть.
- У воды остаётся нормализация мелкого цвета, из‑за которой мель не оранжевая, прежняя мокрота песка у берега и мягкая пена там, где вода сходит на нет. Отдельные слои волн и пены под поверхностью не добавлялись.
- Снег, грязь и песок приподнимаются (по умолчанию 60, 18 и 10 единиц). Нога проваливается примерно на 65% слоя, а старые следы без подъёма остаются как были. Подъём сходит на нет до границы тесселяции и стыкуется с плоской дальней землёй. Мелкие впадины песка у воды понижаются. Ноги в снегу покрываются до поверхности сугроба.
- Обычная сетка воды смещается девятью волнами Герстнера. Реки и водопады (flowmap) не двигаются. Высота сходит в плоскую плоскость между 4000 и 7000 единицами. Глубина у берега — одна сетка высоты земли, общая для сетки воды, камеры и актёров, поэтому линия берега не плывёт за камерой. Последние 4 единицы глубины у берега остаются на этой плоскости. Туман, преломление и каустика считаются от смещённой поверхности.
